# GuitarSuite

An all-in-one electric guitar multi-effect plugin built with [JUCE](https://juce.com/).
Plug your guitar into an audio interface, load GuitarSuite on a track in your DAW and get a full pedalboard – noise gate, compressor, overdrive and wah – in a single plugin.

> **Status:** early development (work in progress). The core signal chain works and the plugin has been tested as a VST3 in REAPER. Many more effects and features are planned – see the [Roadmap](#roadmap).

## Features

The signal flows through the effects in a fixed, pedalboard-style order:

```
Input ─► Noise Gate ─► Compressor ─► Overdrive ─► Wah ─► Output
```

| Effect | Controls | What it does |
|---|---|---|
| **Input / Output** | Input, Output (0–2×) | Gain before and after the whole chain |
| **Noise Gate** | Gate Threshold | Mutes the signal below the threshold; 1 ms attack keeps the pick attack, 50 ms release for a smooth close |
| **Compressor** | On/Off, Amount, Makeup | Envelope-follower compressor; Amount moves the threshold down and the ratio up (1:1 → 10:1) at the same time |
| **Overdrive** | Drive (1–50) | `tanh` soft clipping with parameter smoothing, so turning the knob doesn't produce clicks |
| **Wah** | On/Off, Pedal position, Resonance | State-variable band-pass filter swept from ~250 Hz (heel down) to ~1.8 kHz (toe down) |

All parameters are exposed to the host through `AudioProcessorValueTreeState`, so they can be automated in the DAW (e.g. drawing the wah pedal movement as an automation curve).

## Building

### Requirements

- [JUCE](https://juce.com/get-juce/) (the project was created with JUCE 9.0.2) and the Projucer
- Windows with Visual Studio 2026 (C++ desktop workload)

### Steps

1. Clone the repository:
   ```
   git clone https://github.com/iamlisaaay/GuitarSuite.git
   ```
2. Open `GuitarSuite.jucer` in the Projucer.
3. In **Exporters → Visual Studio 2026 → Module paths**, point every module to the `modules` folder of your JUCE installation (the paths in the repo are local to the author's machine).
4. Click **Save and Open in IDE**.
5. In Visual Studio, select the **Release** configuration and build the `GuitarSuite_VST3` target.
6. The plugin appears in `Builds/VisualStudio2026/x64/Release/VST3/GuitarSuite.vst3`.

## Usage

1. Copy `GuitarSuite.vst3` to `C:\Program Files\Common Files\VST3`.
2. In your DAW, rescan plugins (in REAPER: *Options → Preferences → Plug-ins → VST → Re-scan*).
3. Create a track, set its input to the interface channel your guitar is plugged into and arm it with input monitoring on.
4. Add **GuitarSuite** to the track's FX chain and play.

Tip: start with Input at 1.0 and a low Gate Threshold, then raise the gate until the hum between notes disappears.

## Project structure

```
Source/
├── PluginProcessor.*   – parameters, DSP chain, audio callback
├── PluginEditor.*      – plugin UI (knobs, wah pedal, on/off switches)
├── GateDSP.*           – noise gate
├── CompressorDSP.*     – compressor
├── OverdriveDSP.*      – overdrive
└── ManualWahDSP.*      – wah filter
JuceLibraryCode/        – generated by the Projucer, don't edit by hand
GuitarSuite.jucer       – Projucer project file
```

Each effect is a small standalone class with the same interface (`prepareSampleRate()`, setters for parameters, `processSample()`), so adding a new effect means writing one more class and plugging it into `processBlock()`.

## Known limitations

- Plugin state is not saved yet (`getStateInformation` / `setStateInformation` are empty).
- The processing code expects a stereo track.
- Only tested on Windows in REAPER so far.
